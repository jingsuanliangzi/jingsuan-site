## GitHub Pages
1. 解压 ZIP。
2. 把解压后所有文件直接上传到仓库根目录。
3. Settings → Pages → Deploy from a branch。
4. Branch: main，Folder: /(root)。
5. 域名准备好后，把 `CNAME.pending` 改名为 `CNAME`。
